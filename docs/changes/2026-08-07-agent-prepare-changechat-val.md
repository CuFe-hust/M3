## Modification Goal

Provide a repeatable script that converts the official LEVIR-CC val captions
into the same JSON schema used by `changechat_105k_train.json`, so the val
split can be used alongside ChangeChat-105k without inventing unavailable
generated QA rows.

## Modified Files

- `scripts/prepare_changechat_val.py` (new)
- `tests/test_prepare_changechat_val.py` (new)
- `README.md`
- `DETAILS.md`

## Core Changes

- Added `scripts/prepare_changechat_val.py` with `--annotation`, `--output`,
  `--split`, and `--start-id` options.
- Each official val image pair is converted into five caption instruction rows
  with `id`, `image` (`val/A/...`, `val/B/...`), `changeflag`, and
  `conversations` matching the ChangeChat-105k train format.
- Caption wording is normalized exactly like ChangeChat-105k train rows:
  strip surrounding whitespace, collapse whitespace before punctuation, and
  capitalize the first character. Verified against all 34,075 train caption
  rows before implementation.
- Added unit tests covering split filtering, schema, id sequence, caption
  normalization, and missing-input failure.

## Risks and Follow-up TODOs

The output contains only caption instruction rows. If the val split should
also include binary/count/open/localization/dialogue rows like the ChangeChat
