## Model

(`/home/lijia/M3/models/qwen3_vl_8b/weights`, 8.77B params) with pure LoRA on
the eight `nn.Linear` layers inside the four `Qwen3VLVisionPatchMerger`
modules (`visual.merger` + `visual.deepstack_merger_list.0/1/2`); every other
weight frozen. Inference uses greedy decoding, bf16, sdpa, CUDA.

## Run Commands

Training:

```bash
cd ~/M3
DATA_ROOT=/home/lijia/M3/data/vrsbench \
MODEL_ID=/home/lijia/M3/models/qwen3_vl_8b/weights \
OUTPUT_DIR=outputs/finetune/qwen3-vl-8b-merger-lora \
PYTHON=/home/lijia/miniconda3/envs/m3/bin/python \
PYTHONUNBUFFERED=1 \
nohup bash scripts/finetune_qwen3vl_merger_lora.sh \
  > outputs/finetune/qwen3-vl-8b-merger-lora/run_full.log 2>&1 &
```

Key training hyperparameters: rank 32 / alpha 64 / dropout 0.05, batch 2,
gradient accumulation 16 (effective 32), 1 epoch / 4622 steps, lr 1e-4 cosine,
bf16, gradient checkpointing, image max pixels 1310720, max seq 4096, eval and
save every 250 steps, save_total_limit 3.

Evaluation with LoRA:

```bash
cd ~/M3
/home/lijia/miniconda3/envs/m3/bin/python scripts/evaluate_qwen3vl_merger_lora.py \
  --model-id /home/lijia/M3/models/qwen3_vl_8b/weights \
  --adapter-path outputs/finetune/qwen3-vl-8b-merger-lora \
  --data-root /home/lijia/M3/data/vrsbench \
  --tasks caption vqa --max-images 200 --device cuda:0 --local-files-only \
  --output-path outputs/eval/qwen3-vl-8b-merger-lora/vrsbench_test_200.jsonl
```

Evaluation without LoRA (same arguments, no `--adapter-path`, output
`vrsbench_test_200_base.jsonl`).

## Conclusion

The merger-LoRA Qwen3-VL-8B training converges steadily (validation loss
1.0812 at step 250 -> 0.9376 at step 4622) and completes one full epoch
without failures. On the 200-image VRSBench test subset, the adapter improves
every caption metric over the raw base model (BLEU-4 0.077 vs 0.013, CIDEr
0.243 vs 0.000) and raises VQA exact-match accuracy from 0.2% to 73.7%
(object_existence 90.1%, classification ~58%), while also reducing mean
inference time. These are single-run greedy results on 200 images, not a full
test-set benchmark.
